# 💫 About Me:
Hi there! 👋<br><br>I'm Krish, a gamer and coder who likes building things for fun.<br><br>My main tech stack is React, Vite, JavaScript, C++, Python, CSS, and HTML. <br><br>One of my favorite projects that I've built is the Real-Time Stock Scanner — a real-time momentum stock scanner that screens equities against a 5-pillar model (relative volume, total volume, gap %, price range, and float) to surface low-float stocks showing signs of explosive demand. It runs entirely client-side, has a simulated mode for testing without an API key, and falls back to end-of-day data if the live feed hits a rate limit.<br><br>Fun Facts:<br><br>Gamer at heart 🎮 <br>I like turning random ideas into working apps <br>Always learning something new
